# 📝 SNS風メモアプリ

シンプルで使いやすいSNS風のメモアプリです。ブラウザだけで動作し、ローカルストレージを使用してデータを保存します。

## ✨ 機能

- **メモ投稿** - ユーザー名とテキストでメモを投稿
- **タイムライン表示** - 投稿したメモを時系列で表示
- **いいね機能** - メモにハートマークでリアクション
- **削除機能** - 不要なメモを削除
- **ソート機能** - 新しい順・古い順で表示切り替え
- **一括削除** - すべてのメモを一度に削除
- **ローカルストレージ** - ブラウザに自動的にデータを保存
- **レスポンシブデザイン** - スマートフォン・タブレット対応

## 🚀 使い方

1. `index.html`をブラウザで開く
2. お名前を入力
3. メモを入力
4. 「投稿する」ボタンをクリック
5. タイムラインに投稿が表示されます

### キーボードショートカット
- `Ctrl + Enter` - メモを投稿（テキストエリアにフォーカス時）

## 💾 データ保存

すべてのメモはブラウザの**ローカルストレージ**に保存されます。
- ブラウザを閉じてもデータは保持されます
- キャッシュをクリアするとデータが削除されます
- 同期機能はありません

## 🔒 セキュリティ

- XSS対策としてHTMLエスケープを実装
- ローカル環境でのみ動作（外部通信なし）

## 💡 カスタマイズ

### 色を変更する
`style.css`の以下を編集：
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### フォントを変更する
`style.css`の`font-family`を編集

### 投稿文字数制限を追加
`script.js`の`postMemo()`関数に検証を追加
